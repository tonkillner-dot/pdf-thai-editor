# ระบบแก้ไข PDF ภาษาไทย (Thai PDF Editor)

เว็บแอปพลิเคชันสำหรับแก้ไขเอกสาร PDF เพิ่มกล่องข้อความภาษาไทย เลือกฟอนต์ไทยแท้ได้หลากหลาย ลากย้ายปรับขนาดได้อย่างอิสระ สระและวรรณยุกต์ไม่ลอย ไม่ซ้อน พร้อมระบบส่งออกไฟล์ PDF ที่คงความคมชัดต้นฉบับ 100%

**จัดทำโดย: ครูนภรัฐ (ครูต้น) โรงเรียนบ้านส้อเด่นพัฒนา**

---

## จุดเด่นและคุณสมบัติหลัก (Key Features)

1. **รองรับภาษาไทยแท้ 100% (Full Thai Typography Support)**
   - สระบน (อิ, อี, อึ, อื), ไม้ไต่คู้, และวรรณยุกต์ (เอก, โท, ตรี, จัตวา) แสดงผลถูกต้อง คมชัด ไม่ลอย ไม่ซ้อนทับกัน
   - ตัดคำภาษาไทยอัตโนมัติ (Intl.Segmenter Word Boundary) ข้อความไม่ตัดกลางคำ
   - รวมฟอนต์ไทยยอดนิยม 10 รูปแบบ:
     - **TH Sarabun (สารบัญ):** เอกสารทางการและราชการ
     - **Itim (ไอติม):** ฟอนต์ลายมือน่ารัก เป็นมิตร เหมาะสำหรับสื่อการสอนและแบบฝึกหัดเด็ก
     - **Kanit (คณิต):** สไตล์โมเดิร์น ไร้หัว อ่านง่าย คมชัดสูง
     - **Prompt (พร้อมท์):** เรียบหรู ทันสมัย นิยมในงานออกแบบ
     - **Mali (มะลิ):** ลายมือน่ารัก มีหัว โครงสร้างอบอุ่น
     - **Mitr (มิตร):** สมดุลยอดเยี่ยม อ่านสบายตา
     - **TH Niramit AS (นิรมิต):** คลาสสิก สง่างาม สไตล์แบบเรียน
     - **Kodchasan (คชสาร):** ตัวหนังสือมน สดใส
     - **Chonburi (ชลบุรี):** ตัวหนา โดดเด่น สำหรับหัวข้อ
     - **Krub (ครับ):** โมเดิร์นกึ่งทางการ

2. **เครื่องมือจัดรูปแบบข้อความครบครัน (Rich Text Controls)**
   - ปรับขนาดตัวอักษร (Font Size) ได้อย่างละเอียด
   - สไตล์ตัวหนา (Bold), ตัวเอียง (Italic)
   - จัดตำแหน่งข้อความ: ชิดซ้าย, กึ่งกลาง, ชิดขวา
   - เลือกสีตัวอักษรและสีพื้นหลังกล่อง (พร้อมชุดสีสำเร็จรูป)
   - เปิด/ปิด เส้นกรอบกล่องข้อความ
   - คัดลอก (Duplicate) และ ลบ (Delete) ได้ในคลิกเดียว

3. **สแตมป์สำเร็จรูปสำหรับคุณครู (Quick Stamps)**
   - เครดิต: จัดทำโดย ครูนภรัฐ (ครูต้น)
   - ตรวจแล้ว ✓ วันที่ ....................
   - ยอดเยี่ยม ★★★
   - กรอกชื่อ-นามสกุล / ชั้น / เลขที่
   - ช่องกรอกคะแนน (... / 10)

4. **เครื่องมือเปิดและจัดการไฟล์ (PDF File Management)**
   - เปิดไฟล์ PDF ใดๆ จากเครื่องคอมพิวเตอร์ หรือลากวาง (Drag & Drop)
   - มีปุ่ม **"ไฟล์ตัวอย่าง"** สำหรับทดลองใช้งานได้ทันทีใน 1 คลิก
   - รองรับเอกสารหลายหน้า (Multi-page PDF) พร้อมแถบดูภาพรวมและสลับหน้าอย่างรวดเร็ว
   - ย่อ-ขยายหน้าเอกสาร (Zoom In / Zoom Out / 100%)
   - ระบบเลิกทำ / ทำซ้ำ (Undo / Redo)

5. **ระบบส่งออก PDF คมชัดสูง (High-Fidelity Vector Overlay Engine)**
   - รักษาความคมชัดของภาพ เวกเตอร์ และตัวอักษรต้นฉบับ 100%
   - ซ้อนเลเยอร์ข้อความภาษาไทยด้วยความละเอียดระดับสิ่งพิมพ์ (300 DPI)

---

## เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4 + Lucide Icons
- **PDF Core:** PDF.js (Mozilla) + pdf-lib
- **Font Rendering Engine:** Google Fonts (Sarabun, Itim, Kanit, Prompt, Mali, Mitr, Niramit, etc.) + HTML5 High-DPI Canvas

---

## วิธีติดตั้งและรันในเครื่อง (Local Setup)

```bash
# ติดตั้ง dependencies
npm install

# รันในโหมด Development
npm run dev

# ตรวจสอบและสร้างไฟล์ Production Build
npm run build
```
